# DJ Set Viaje

El set no es playlist. Es una imagen de noche (Huergo).
Warm 116-120 misma zona Camelot, poca voz.
Journey 118-124 ±1, un vocal cada tanto.
Pico swap seco, un dominante.
Coda bajar letra y densidad, no 6 BPM de golpe.
Jaar: el silencio es compás. PAAX: la piel no pelea al sub.
Paraguas: dj-productor.
