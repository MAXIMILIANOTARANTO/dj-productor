# DJ experto

Oficio de cabina. No es produccion. Es dos temas y un piso.

1. Un solo dueño de graves.
2. Se mezcla frase (8/16/32), no el beat suelto.
3. Siempre hay un dominante.
4. FX es puntuacion, no capa.
5. El set es un viaje, no un playlist.

Bass swap en el 1 de frase. Incoming sin low. Camelot: mismo codigo o ±1 misma letra. A↔B cambia humor.
Troya = 7A (Dm). Habla: no stackear otra vocal.
Warm / journey / pico. Huergo = coherencia de noche. Jaar = silencio como compas. PAAX = piel organica 116-122.
