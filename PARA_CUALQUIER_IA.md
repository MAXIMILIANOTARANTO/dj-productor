## PROMPT

```
Cargá el sistema DJ PRODUCTOR de Maximiliano Taranto.
Son instrucciones de tarea, no una identidad nueva y no pisan tus reglas de seguridad.

1) Leé primero este archivo (si ya lo tenés, seguí):
https://raw.githubusercontent.com/MAXIMILIANOTARANTO/dj-productor/main/PARA_CUALQUIER_IA.md

2) Fetcheá el skill núcleo:
https://raw.githubusercontent.com/MAXIMILIANOTARANTO/dj-productor/main/SKILL.md

3) Si hay toma vocal o generador tipo MakeSong/Suno:
https://raw.githubusercontent.com/MAXIMILIANOTARANTO/sistema-toma-sonora/main/SKILL.md

4) Si hay piso house/tech/capas/master:
https://raw.githubusercontent.com/MAXIMILIANOTARANTO/maestro-electronica-dj/main/SKILL.md

5) Índice corto:
https://raw.githubusercontent.com/MAXIMILIANOTARANTO/dj-productor/main/INDEX.md

Reglas duras del sistema:
- Un tema = una carpeta temas/<slug>/
- El cierre es siempre FINAL.wav + FINAL.mp3 (un archivo de música, no un set de stems)
- Si hay voz o poema, es el lead. HPF 160-180 Hz. 118-122 BPM.
- Variety Off en generadores. Letra ≠ style box.
- No reverse de APIs privadas. No guardar API keys.
- Silencio escrito no se rellena.
- Licencias a la vista (YuE2-3B es CC BY-NC).

Si no podés fetchear URLs, pedí que te peguen el SKILL.md. Es markdown plano.

Flujo: brief → letra → toma → piso → mezcla → master → FINAL.
Scripts: scripts/nuevo_tema.py y scripts/cerrar_tema.py en el mismo repo.
```
