# DJ Armonía

Mismo código = blend invisible.
±1 misma letra = sube o baja energía.
A↔B mismo número = cambia humor.
Troya = Dm = 7A. Encima 7A / 6A / 8A / 7B.
Con voz lead no montar otra voz. Montar instrumental.
Key-lock si el pitch mueve el tono.
Paraguas: dj-productor.
