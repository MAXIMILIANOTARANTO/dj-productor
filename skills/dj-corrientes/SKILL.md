# DJ Corrientes

limpia     intelligibilidad de habla. Poco mid-bass.
tech       graves + medios. Punch 180-250. Hats 16th. 124-128 o 118 con voz.
organica   ritual. Shaker, tierra, silencio (Jaar/PAAX). 116-122.
constante  tool. 4/4 sin quiebres. Para mezclar encima.

Kick y sub a la tonica. Dm = 7A.
Huergo = el viaje de la noche elige corriente, no al reves.
Paraguas: dj-productor.
